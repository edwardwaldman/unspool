# "oh you don't wanna read all that??"

11 seconds, no voiceover, cut on a 120 bpm beat: the format winning for study apps right now (Coconote's
"oh he don't wanna read all that??" demo, 11.9M views; Answer.AI's text-overlay demos, 25M; ~11 s, music-driven,
relatable question hook, the app shown working, minimal CTA). TikTok-style white text boxes, Maya as a green-screen
creator, a 47-page chapter scrolling, the drop into Unspool, real reels swiping on the beat, the quiz, the A,
"app: unspool.cc". `unspool-ad-dont-wanna-read-silent.mp4` is for posting with a trending sound added in TikTok.

Web assets are copied from `brand/ads/shared/` (maya-*.png, mito/resp/dna/r1.jpg) and `brand/fonts/InstrumentSans-600.ttf`.
Render: `node brand/ads/tools/render-fresh.mjs <dir> 6`, then `bash brand/ads/tools/encode.sh <dir> dont-wanna-read`.
