# What if you fell INTO your textbook? (20s)

Format: the "what if" falling journey (timer chip, caption up top, live stats bar, speech bubbles), told entirely on screen.
No voiceover and a silent audio track, so any sound or trend audio can be laid over it.

Beats: desk hook (0) -> page swallows you (2.2) -> page 48 knight (3.4) -> page 210 cell (5.6) -> page 455 word-problem train (7.8)
-> page 600, "12 hours later", remember nothing (10.0) -> drop it into unspool.cc, chapters become reels you ride back up, quiz each (12.0)
-> end card "send this to a friend with a test tomorrow" + unspool.cc (17.5).

The reading clock and page counts are the story's own counters, not claims about real books or about Unspool.

Render: `node brand/ads/tools/render-fresh.mjs <dir> 4` then `bash brand/ads/tools/encode.sh <dir> fell-into-your-textbook` (dir needs web/ and a 20s silent mix.wav).
