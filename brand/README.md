# Unspool brand kit

unspool.cc — "One document into reels." Everything here is generated by `scripts/generate.mjs`
(`cd brand/scripts && npm install && node generate.mjs`). SVG sources for every marketing PNG are in `masters/`. See `contact-sheet.png` for an overview.

## Fonts (in `fonts/`, SIL OFL, from Google Fonts)
- **Syne 800** — wordmark only, lowercase "unspool", tracking -0.02em.
- **Unbounded 700** — marketing headlines ("One document **into reels**", accent words in thread).
- **Instrument Sans 400–600** — body, UI, captions, URLs.

Taglines: "One document into reels." / "Skip the 40-page read."

## Logo usage
- Mark = spool + thread + reel with play triangle (geometry = `public/icon.svg`, 64 grid).
- Clear space: at least the mark's flange height x2 (≈ 25% of mark height) on all sides.
- Minimum size: mark 16 px (favicon); horizontal lockup 96 px wide; wordmark 64 px wide.
- On dark: `mark.svg`, `mark-transparent.svg`, `wordmark.svg`, `lockup-*.svg`. On white/light: `mark-light-bg.svg`, `wordmark-dark.svg`, `lockup-*-light.svg`.
- Don't: recolor the mark outside these schemes, add gradients/shadows/glows, round the corners, stretch, rotate, set the wordmark in another font or uppercase, put the chartreuse version on white.

## Platform notes
- Profile images (X, IG, TikTok, YT, FB, LinkedIn) are cropped to circles: glyph is scaled to 74% so corners stay inside.
- Stories/TikTok: nothing important in the top 250 px or bottom 340 px; TikTok grid crops to centre 3:4.
- YouTube: banner safe area 1546×423 centred; outer area only shows on TV/wide desktop.
- Facebook cover: mobile shows only centre ~1110 px; avatar overlaps bottom-left on desktop.
